## Notes for Using GIFT Format:

1. **Correct answers** start with `=`
2. **Wrong answers** start with `~`
3. **Feedback** can be added after `#`
4. **Categories** are set with `$CATEGORY: name`
5. **Special characters** need escaping with backslash: `\=`, `\~`, `\#`, `\{`, `\}`
6. **Multiple correct answers** are supported for short answer questions
7. **True/False** questions use `{T}`, `{F}`, `{TRUE}`, or `{FALSE}`
8. **Essay questions** use empty braces `{}` and are converted to short answer
9. **Code** should be escaped or you can use HTML entities
10. **Blank lines** separate questions

## Tips:

- Keep questions clear and concise
- Use feedback to help students learn
- Test your GIFT format before importing
- Use the "View Example" button in the import modal
- Categories help organize questions by topic
- Use code blocks for programming questions
- Escape special characters properly
